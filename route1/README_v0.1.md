# 会议注意力检测系统 - 开发日志 [版本0.1]

## 项目目的
基于视频的员工注意力检测系统，用于监测会议/班前会中员工的注意力状态，及时发现异常行为（疲劳、分心、情绪失控等）。

---

## 双路线策略

### 路线1: YOLO-Pose + ByteTrack + 规则/模型（本路线）
- **技术栈**: YOLOv8-Pose + ByteTrack多目标跟踪 + 规则阈值引擎 + CNN-LSTM分类
- **合并策略**: 将原"思路1（CNN-LSTM）"和"思路2（规则引擎）"合并为统一路线
- **适用场景**: 实时预警、低延迟检测
- **开发阶段**:
  - 阶段1: ByteTrack + 规则引擎（当前）
  - 阶段2: CNN-LSTM深度模型（后期）

### 路线2: 多模态大模型直接分析
- **技术栈**: 视频帧采样 + 通义千问VL/GPT-4V/Ollama
- **适用场景**: 离线复盘、零样本快速原型、数据标注辅助
- **独立开发**: 在 `route2/` 目录独立实现

## 当前进展

### 步骤0.1: 创建项目结构（已完成）
**目标**: 建立清晰的项目目录结构

**实现方案**:
采用分层模块化目录结构，将核心计算、模型、处理器、规则引擎分离。

**目录结构**:
```
route1/
├── src/                    # 源代码
│   ├── core/               # 核心计算模块（几何计算）
│   ├── models/             # 模型模块（YOLO-Pose）
│   ├── trackers/           # 多目标跟踪模块（ByteTrack）
│   ├── processors/         # 处理器模块（RFAC计算）
│   ├── rules/              # 规则阈值引擎
│   ├── utils/              # 工具函数
│   └── config/             # 配置文件
├── tests/                  # 测试脚本
├── data/                   # 数据目录
│   └── videos/             # 测试视频
├── main_rules.py           # 规则引擎入口
└── requirements.txt        # 依赖清单
```
