# 会议注意力检测系统 - 开发日志 [版本2.0]

## 项目目的
基于视频的员工注意力检测系统，用于监测会议/班前会中员工的注意力状态，及时发现异常行为（疲劳、分心、情绪失控等）。

---

## 双路线策略

### 路线1: YOLO-Pose + ByteTrack + 规则/模型（本路线）✅ MVP完成
- **技术栈**: YOLOv8-Pose + ByteTrack多目标跟踪 + 规则阈值引擎 + CNN-LSTM分类
- **适用场景**: 实时预警、低延迟检测
- **当前状态**: 规则引擎MVP已完成，可投入使用

### 路线2: 多模态大模型直接分析（待开发）
- **技术栈**: 视频帧采样 + 通义千问VL/GPT-4V/Ollama
- **适用场景**: 离线复盘、零样本快速原型、数据标注辅助
- **开发位置**: `route2/` 目录

**系统架构**:
```
┌───────────────────────────────────────────────────────────────┐
│                        视频输入                                 │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                    ByteTrack跟踪器                              │
│              （确保track_id跨帧一致）                            │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                    YOLO-Pose检测                                │
│              （提取17个关键点）                                  │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                    RFAC四维度计算                               │
│   Apathy(50%) | Fatigue(20%) | Rushing(15%) | Frustration(15%) │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                    规则阈值引擎                                  │
│              （0-3级异常判定）                                   │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                    可视化输出                                    │
│              （实时显示/视频保存）                               │
└───────────────────────────────────────────────────────────────┘
```

**关键改进点**:
| 特性 | 旧方案(CV/) | 新方案(route1/) |
|------|-------------|-----------------|
| 人员ID | 帧内索引，跨帧不一致 | ByteTrack track_id，跨帧一致 |
| 跟踪模块 | 无集成 | ByteTrackManager |
| 异常判定 | 连续评分 | 0-3级分级 |
| 规则配置 | 硬编码 | RuleThresholds可配置 |
| 干预建议 | 无 | get_intervention_suggestion() |

**使用指南**:

```bash
# 进入目录
cd route1

# 快速测试（100帧，无显示）
python main_rules.py --frames 100 --no-display

# 完整运行
python main_rules.py --video data/videos/meeting_attention_video.mp4

# 保存结果
python main_rules.py --video data/videos/meeting_attention_video.mp4 --save --output result.mp4

# 跟踪测试
python tests/test_tracking.py --no-display
```
